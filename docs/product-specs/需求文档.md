# 嘉立创 EDA AI 助手插件需求文档

## 1. 文档信息
- 文档版本：v0.2（修订）
- 文档版本：v0.3（修订）
- 创建日期：2026-03-24
- 适用范围：嘉立创 EDA 标准版与专业版插件（原理图场景）

## 2. 项目背景与目标
目标是开发一个可在嘉立创 EDA 中使用的 AI 助手插件，帮助用户理解和检查原理图，减少接线错误与属性配置错误，提高绘图与评审效率。

核心目标：
- 识别并解析当前原理图的元件、网络与连接关系。
- 自动分析常见接线错误并给出定位与修复建议。
- 识别并校验元件关键属性（封装、数值、位号、电气类型等）。
- 支持基于自然语言的 AI 绘制原理图与局部自动补全。
- 接入 RAG 知识系统，为 LLM 提供电子原理与元件知识上下文，提升理解与推理准确性。
- 以可交互方式展示分析结果，支持一键跳转定位问题对象。

## 3. 用户角色
- 硬件工程师：进行原理图设计、快速自检与评审。
- 电子初学者：借助 AI 解释连接逻辑与器件作用。
- 审核人员：在评审阶段快速发现规则与连接异常。

## 4. 使用场景
- 场景 A：绘图过程中实时检查新增连接是否异常。
- 场景 B：提交前一键全图体检，生成问题列表。
- 场景 C：选中某个器件后，查看属性完整性与风险提示。
- 场景 D：根据网络名/电源网，分析连接拓扑是否合理。

## 5. 功能需求

### 5.1 原理图识别与解析
- 读取当前工程原理图数据（页面、器件、引脚、网络、连线、标签、端口）。
- 建立统一数据模型：
  - 元件模型：位号、名称、器件库 ID、封装、数值、属性集合。
  - 网络模型：网络名、连接点、跨页连接关系。
  - 拓扑模型：引脚到网络、网络到网络、器件间依赖关系。
- 支持多页原理图解析与跨页网络合并。

### 5.2 接线错误识别
需至少覆盖以下规则类型：
- 悬空检测：应连接但未连接的引脚、孤立网络段。
- 短接/冲突：不应直接相连的网络被短接（如不同电源域）。
- 电气类型冲突：输出对输出、输入悬空、无驱动输入等。
- 电源连接异常：电源网命名不一致、去耦缺失、地网断裂风险。
- 接线标准符合性：根据元件接线标准/典型应用检查是否接错、接反（如极性器件正负端反接、接口引脚定义接反、关键控制脚误连）。
- 差分/关键网络异常（可选增强）：差分对命名或配对不一致。

输出要求：
- 每条问题包含：问题类型、严重级别、对象定位、原因说明、修复建议。
- 支持点击问题项后高亮原理图对应对象。

### 5.3 元件属性识别与校验
- 属性提取：位号、器件名、封装、数值、容差、额定电压/电流、供应链字段等。
- 完整性检查：
  - 必填属性缺失（如封装、位号重复）。
  - 属性格式错误（如数值单位不规范）。
  - 属性与器件类别不匹配（如电阻无阻值、电容无耐压）。
- 一致性检查：
  - 同类器件命名/标注风格一致性。
  - 器件与封装映射一致性（符号-封装匹配）。

### 5.4 AI 辅助分析与解释
- 提供自然语言问答：可询问“某模块功能”“某网络作用”“问题为什么出现”。
- 输出可解释结论：基于识别数据给出证据链（相关器件、网络、规则）。
- 给出可执行建议：建议应可定位、可操作，不仅是笼统提示。

### 5.5 插件智能体实现要求
- 插件内智能体需遵循 `ReAct` 模式进行任务求解。
- 智能体在执行分析、问答、绘图建议和问题定位时，应具备“推理-行动-观察”闭环，而非单次黑盒回答。
- 智能体需支持 `Tool Calling`：
  - 调用原理图读取工具。
  - 调用规则检查工具。
  - 调用 RAG 检索工具。
  - 调用绘图草案生成与对象定位工具。
- 智能体需支持 `MCP` 接入模式：
  - 用于统一对接外部知识、结构化数据、工具服务或扩展能力。
- 智能体需支持 `Skill` 机制：
  - 支持按任务装载特定技能，如原理图分析、元件知识解释、绘图辅助、设计规范检查。
  - 技能需可扩展、可配置、可按场景启停。
- 智能体输出要求：
  - 关键结论需说明所调用的工具、规则或知识来源。
  - 高风险结论不能仅依赖模型自由生成，必须结合规则或工具证据。

### 5.6 交互与体验
- 插件面板包含：
  - 解析状态区（成功/失败、耗时、页数）。
  - 问题列表区（按严重级别筛选）。
  - 详情区（原因、建议、影响范围）。
- 支持操作：
  - 一键“全图分析”。
  - 对当前选中对象“局部分析”。
  - 导出分析报告（文本/JSON）。

### 5.7 AI 绘制原理图
- 支持自然语言生成原理图草案：
  - 输入示例：`画一个 5V 转 3.3V 的 LDO 供电模块`。
  - 输入示例：`帮我生成一个智能药盒项目，采用 esp32-s3 + 功放喇叭 + 麦克风 + 多个按键 + 霍尔感应器`。
  - 输出内容：器件选择建议、连接关系、关键网络命名、基础属性建议。
- 支持“从描述到图形对象”：
  - 首版先生成原理图草案，不直接无确认落图。
  - 草案需包含器件清单、连接关系、关键网络与主要属性建议。
  - 用户确认草案后，再生成并应用原理图图形对象。
- 支持局部自动补全：
  - 基于已选模块补全去耦、电源指示、上拉/下拉等常见电路。
  - 补全前给出变更预览（新增器件/连线/属性）。
- 生成约束要求：
  - 生成连接必须经过规则引擎校验后方可提交。
  - 对高风险连接给出阻断提示（如电源短接风险）。

### 5.8 RAG 知识系统接入
- 接入知识库类型：
  - 电子原理知识库（基础电路、典型拓扑、设计规范、失效模式）。
  - 元件知识库（器件参数、典型应用、封装信息、注意事项）。
- 首版范围约束：
  - 首版不接入企业私有规范知识库。
  - 首版聚焦通用电子原理知识与元件知识。
- 检索与增强流程：
  - 用户提问或分析任务触发检索，返回 Top-K 证据片段。
  - LLM 回答必须绑定引用来源（文档 ID/条目 ID/版本号）。
  - 支持按项目上下文过滤（电压等级、器件类别、应用场景）。
- 知识更新机制：
  - 支持知识条目增量更新与版本管理。
  - 支持知识生效范围配置（全局/项目级）。
- 质量要求：
  - 回答优先引用知识库事实，降低幻觉输出。
  - 当检索证据不足时明确提示“不确定”，禁止编造器件参数。

### 5.9 登录与账户能力
- 插件需支持账户登录，以承载服务端 Credits 消费模式。
- 支持登录方式：
  - 邮箱验证码登录。
  - 微信扫码登录。
- 登录交互要求：
  - 登录页面不在插件内实现。
  - 插件通过系统默认浏览器打开登录页。
  - 登录成功后，插件通过服务端登录会话状态完成自动登录。
- 首版要求：
  - 邮箱验证码登录作为首版主登录方式。
  - 微信扫码登录纳入需求范围，但受微信开放平台资质与审核要求约束。
- 账户能力要求：
  - 支持查看当前登录状态。
  - 支持退出登录。
  - 支持展示 Credits 余额与账户基础信息。
  - 支持同一账户下邮箱与微信身份绑定。
- 用户范围约束：
  - 首版仅支持个人用户。
  - 团队/组织能力暂不纳入首版范围，但需保留后续快速接入空间。

## 6. 非功能需求
- 性能：
  - 中小型原理图（<= 500 器件）全图分析时间目标 <= 5 秒。
  - 大型原理图（<= 2000 器件）全图分析时间目标 <= 20 秒。
  - RAG 检索响应时间目标 <= 2 秒（常规查询）。
  - AI 生成小模块原理图（<= 20 器件）目标 <= 8 秒。
  - 登录状态同步目标：用户完成浏览器登录后，插件侧 `<= 5 秒` 内感知登录成功。
- 准确性：
  - 常见接线错误召回率目标 >= 90%（基准样例集）。
  - 高严重级别误报率目标 <= 10%。
  - RAG 引用命中率目标 >= 95%（回答包含有效引用）。
  - AI 绘制结果一次通过基础规则检查比例目标 >= 85%。
- 稳定性：
  - 插件分析失败不影响 EDA 基本编辑能力。
  - 异常场景需返回可理解错误信息。
- 可维护性：
  - 规则引擎可配置，支持新增/停用规则。
  - 日志可追踪（含规则命中与分析耗时）。

## 7. 系统边界与约束
- 本阶段聚焦原理图，不覆盖 PCB 布线 DRC 全流程。
- 首版目标平台覆盖嘉立创 EDA 标准版与专业版双端。
- 依赖嘉立创 EDA 插件 API 获取工程与对象数据。
- AI 分析需结合本地规则引擎，避免纯模型黑盒判断。
- 插件智能体需遵循 `ReAct + Tool Calling + MCP + Skill` 的实现约束。
- AI 绘制必须走“生成-校验-确认”闭环，不能直接无校验落图。
- RAG 数据源需可追溯，知识条目需可版本化管理。
- 登录首版采用“浏览器登录 + 服务端会话 + 插件状态同步”方案。
- 微信扫码登录依赖微信开放平台网站应用能力，不能默认等同于公众号网页登录能力。
- 需考虑用户设计数据隐私：默认本地处理，外发前需明确提示。

## 8. 需求优先级（MVP）
- P0（首版必须）：
  - 标准版与专业版双端基础兼容。
  - 原理图基础解析（元件/网络/连接）。
  - 常见接线错误检测（悬空、短接、电气冲突）。
  - 元件基础属性校验（封装、位号、数值）。
  - 智能体基础框架（`ReAct` 编排 + 工具调用 + 技能装载）。
  - AI 绘制原理图基础能力（描述生成草案 + 人工确认后落图）。
  - RAG 基础接入（电子原理 + 元件知识两类库，支持引用返回）。
  - 邮箱验证码登录与账户状态同步。
  - 问题列表与定位跳转。
- P1（次优先）：
  - 多页复杂网络增强分析。
  - 报告导出与问题分组管理。
  - AI 自然语言解释与问答增强（基于 RAG 证据）。
  - 局部自动补全（去耦/上拉下拉/保护器件建议）。
  - 微信扫码登录。
- P2（后续）：
  - 个性化规则模板。
  - 供应链风险联动提示。
  - 历史版本对比分析。

## 9. 验收标准
- 能在嘉立创 EDA 中成功安装并打开插件面板。
- 能在嘉立创 EDA 标准版与专业版中完成基础运行与核心功能调用。
- 对给定测试原理图可输出结构化问题列表。
- 每个问题可定位到具体元件/网络/引脚。
- 输入典型需求文本后，能够先生成可预览草案，经用户确认后成功落图。
- AI 问答输出需携带知识库引用，且引用可追溯到具体条目。
- 智能体在关键任务中可展示工具调用结果或证据来源。
- 能通过系统浏览器完成邮箱验证码登录，并在插件侧自动进入已登录状态。
- 至少覆盖 P0 规则并在样例集中达到目标准确性。
- 对异常输入（缺页、损坏对象）有稳定错误处理。

## 10. 里程碑建议
- M1（1-2 周）：完成数据读取与原理图统一模型。
- M2（2-3 周）：完成 P0 规则引擎与问题定位能力。
- M3（1-2 周）：完成浏览器登录页、邮箱验证码登录、插件登录状态同步闭环。
- M4（2 周）：完成 RAG 基础接入与引用链路。
- M5（2 周）：完成 AI 绘制小模块能力与生成校验闭环。
- M6（1 周）：完成插件 UI 面板联调、测试样例、性能优化与首版发布。

## 11. 风险与待确认项
- 待确认：嘉立创 EDA 插件 API 是否完整提供引脚电气类型与跨页连接信息。
- 待确认：插件 API 是否支持可靠的程序化放置器件、连线与批量撤销。
- 待确认：RAG 知识源范围（官方文档、公开设计规范、器件手册）及授权方式。
- 待确认：嘉立创插件环境是否支持稳定打开系统浏览器并完成登录态回传。
- 待确认：微信开放平台网站应用资质是否满足扫码登录接入要求。
- 待确认：嘉立创插件运行环境对 `MCP`、工具调用链和技能动态装载的适配边界。
- 待确认：标准版与专业版在插件 API、对象模型和能力范围上的差异边界。
- 风险：不同器件库属性格式差异大，可能导致校验规则误报。
- 风险：知识库数据质量不一致会影响检索与回答可靠性。
- 风险：AI 生成电路存在“看似合理但工程不可用”的隐患，需强规则兜底。
- 风险：仅依赖 AI 推理会不稳定，需要规则与模型联合策略。
