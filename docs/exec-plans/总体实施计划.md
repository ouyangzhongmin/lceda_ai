# 总体实施计划

## 1. 计划目标
- 在嘉立创 EDA 标准版与专业版双端交付首个可用的 AI 助手插件版本。
- 首版完成原理图分析、问题定位、草案生成、邮箱登录、Credits 模式与基础 RAG 闭环。

## 2. 计划原则
- 先验证关键能力，再进入全面实现。
- 优先打通从插件到 Go 服务端的最小闭环。
- 所有高风险功能都必须先有可观测与可回退方案。
